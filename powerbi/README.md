# Power BI Project File

## Overview

This folder contains the Microsoft Power BI Desktop project file developed for Building Advanced Data Models and DAX Calculations.

## Project File

**Filename:** `Construction_Project_Analytics.pbix`

## Included Work

The Power BI file contains:

- Imported construction project datasets.
- Power Query data transformations.
- Four-table relational data model.
- Three active table relationships.
- DAX measures and KPI calculations.
- Construction Project Analytics Dashboard.
- Project status and province visualisations.

## How to Open

1. Download the `.pbix` file.
2. Install Microsoft Power BI Desktop.
3. Open the downloaded file using Power BI Desktop.
4. If Power BI requests access to the original CSV files, update the data source paths to the downloaded files in the `data` folder.
5. Refresh the data if required.

## Note

The project was developed using publicly available ZEPRA datasets. Some calculations are limited by missing information in the original source records.
